# 视觉系统

生成底图时读取本文件。目标是系列稳定、每日构图有新鲜感，而不是逐像素套模板。

## 固定骨架

| 元素 | 规则 |
|---|---|
| 画布 | 1024×1536 PNG，2:3 竖版 |
| 气质 | 暖象牙白/米白纸张、柔和晨光、克制金色；高级商业杂志与现代知识品牌感 |
| 日期卡 | 右上安全区，米白纸卡、轻阴影、两个金色图钉；星期与 `YYYY.MM.DD` 清晰准确 |
| 人物 | 下半区偏右，约占画面 1/3；使用配置肖像锁定谷燕燕脸部、发型与气质 |
| 二维码区 | 左下基准区域 `x=28, y=1260, 224×224`，底图保持自然干净 |
| Logo 区 | 右下基准区域 `x=650, y=1343, 320×213`，与二维码处在同一底部视觉带 |
| 人物标签 | 人物右侧双列竖排：左列 `谷燕燕`，一根细金色竖线，右列 `AI + OPC 实战导师` |

## 文字层级

1. 主标题 12–22 个汉字、两行内；清晰、有力度的中文手写或毛笔字，先读到。
2. 星期标签使用细衬线大写英文与高字距，例如 `WEDNESDAY PRACTICE`。
3. 中文正文为细宋/明朝体，2–3 行，行距舒展。
4. 英文点缀短、自然、清晰，不做逐字硬译。
5. 画面只出现内容包锁定的文字。辅助纸张、书本、墙面和道具使用无字纹理或抽象笔触。

## 每日变化

让人物动作、表情、光影、桌面、书本、纸张、植物、金色曲线和视觉隐喻服务当天观点。例如：行动可用前倾/手势，复盘可用翻阅资料，判断可用便签与思考，连接可用温和侧身。

同一周内不重复核心视觉隐喻。优先使用纸张、光线、路径、种子、阶梯、窗口、书页等人本元素；不使用机器人、电路板、大面积黑底、霓虹、重赛博或廉价培训海报语言。

## Imagegen 底图合同

在提示中逐字列出日期、星期、主标题、标签、正文、英文和人物介绍，并声明它们是唯一允许出现的文字。人物参考图只用于身份保持，输入图中的棋盘格必须完全替换为新场景。

底图的底部约 18% 形成自然的浅色前景带。该区域不画二维码、二维码纹样、二维码白框、Logo、品牌字标、水印或额外文案。二维码与 Logo 在底图通过后由确定性脚本加入。
